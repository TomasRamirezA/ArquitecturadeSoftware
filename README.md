# Portafolio de Arquitectura de Software (ARSW)

Este repositorio contiene los laboratorios y el proyecto final desarrollados durante el curso de Arquitectura de Software. A lo largo del curso se abordaron conceptos fundamentales de concurrencia, paralelismo, desarrollo web (Backend y Frontend), tiempo real y despliegue de infraestructura en la nube.

## 🧪 Laboratorios

*   **Lab 1: Paralelismo, Arquitectura y Calidad desde el Día 1**
    *   Cálculo de los dígitos de Pi integrando buenas prácticas de diseño.
    *   Uso de Java 21, Spring Boot 3.3, concurrencia (Platform Threads) y Swagger para documentación de API REST.

*   **Lab 2: Programación Concurrente - Carrera de Galgos**
    *   Sincronización de hilos y manejo de regiones críticas.
    *   Implementación de pausas y reanudación usando `wait()` y `notifyAll()`.

*   **Lab 3: Inmortales y Sincronización**
    *   Resolución de problemas clásicos de concurrencia (Productor/Consumidor).
    *   Uso de cerrojos (Locks), variables atómicas (AtomicInteger) y diagnóstico y solución de interbloqueos (Deadlocks).

*   **Lab 5: BluePrints API con Seguridad JWT (OAuth 2.0)**
    *   Desarrollo de una API REST protegida para gestión de planos.
    *   Implementación de autenticación segura JWT, roles de acceso, persistencia dual (Memoria y PostgreSQL) y cobertura de pruebas.

*   **Lab 6: BluePrints API - UI (React)**
    *   Desarrollo de la interfaz de usuario en React para la API de BluePrints.
    *   Manejo del estado global con Redux, llamadas asíncronas usando Axios y renderizado interactivo en Canvas HTML5.

*   **Lab 7: BluePrints en Tiempo Real (Sockets & STOMP)**
    *   Colaboración y dibujo en tiempo real utilizando WebSockets.
    *   Implementación con Socket.IO en Node.js y STOMP en Spring Boot.

*   **Lab 8: Infraestructura como Código con Terraform (Azure)**
    *   Aprovisionamiento de un entorno escalable y seguro en Microsoft Azure usando Terraform.
    *   Configuración de un Load Balancer y Máquinas Virtuales en red privada.

## 🚀 Proyecto Final

*   **Proyecto ZOmbiland**
    *   **ZOmbiland-Backend**: Aplicación Spring Boot que provee los servicios core del sistema.
    *   **ZOmbiland-Frontend**: SPA construida en React + Vite para la interfaz visual e interactiva.
